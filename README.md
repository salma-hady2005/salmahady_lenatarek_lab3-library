# Library Management System

## Project Overview
This project is a web-based Library Management System developed using Python, Flask, and MySQL. It allows users to register and log in and provides an interface for managing library book and author information.

## Features

- Displaying library books
- Managing book and author information
- Uploading book cover images
- Uploading author images
- Storing library data in a MySQL database

## Database
The project uses MySQL to store information about books and authors. The database setup files are included in the repository.

## How to Run
1. Install Python and MySQL.
2. Clone or download this repository.
3. Install the Python packages required by the application.
4. Import the database using the provided SQL file.
5. Configure the database connection settings.
6. Run `app.py` from the `website` folder.
7. Open the local address shown in the terminal in your browser.
